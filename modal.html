Dialog

This modal is designed following WAI-ARIA guidelines. It features focus trapping, responds to the Escape key to close, and manages ARIA states for screen readers. Coupled with a premium dark mode, solid-color flat design.

Accessibility Standards

Keyboard Navigation

The dialog component fully manages focus trapping and accessibility keys according to W3C WAI-ARIA guidelines:

Key Function
Tab Focuses the next focusable element within the dialog window. Traps focus so the user cannot navigate to background page elements.
Shift + Tab Focuses the previous focusable element inside the dialog window. Traps focus within the dialog.
Escape Closes the active modal dialog box instantly and returns the focus to the button that triggered the opening event.
Space / Enter Activates focused trigger buttons to either open or close the modal window.

ARIA Roles & Attributes

The markup uses semantic ARIA properties to communicate the state of the dialog to screen readers:

ARIA Role / Attribute Target Element Description / Usage
role="dialog" Modal Box Identifies the HTML container as a dialog window, changing screen reader modes.
aria-modal="true" Modal Box Indicates to assistive technologies that the background page content under the dialog window is inactive and cannot be accessed.
aria-labelledby="[ID]" Modal Box Points to the heading element (id="modal-title") to assign it as the accessible heading name of the modal.
aria-describedby="[ID]" Modal Box Points to the main body paragraph (id="modal-desc") to supply an accessible description for screen readers upon dialog activation.
aria-hidden="true / false" Overlay Box Indicates whether the dialog tree should be hidden or visible inside the screen reader's accessibility page tree.
aria-label="Close dialog" Close Button Supplies a clear, accessible text name for the close button SVG, as it lacks readable text content.
