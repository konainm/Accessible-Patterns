Menubar

A desktop-style horizontal menu bar implementing the W3C WAI-ARIA Authoring Practices Guide (APG) Menubar pattern, with roving tabindex, nested submenus, checkbox and radio menu items, and full keyboard navigation.

W3C APG Note: A role="menubar" is a single-tab-stop composite widget designed for desktop-style application menus and rich toolbars. For standard website navigation links, the W3C APG recommends a simpler disclosure pattern unless arrow-key menu semantics are specifically required.

Accessibility Standards

Keyboard Navigation

The menubar component follows the W3C WAI-ARIA Authoring Practices Guide (APG) composite keyboard model:

Key Context Function
Tab / Shift + Tab Entering or exiting Moves focus into the menubar (onto the active top-level item) or exits the entire menubar, closing any open submenus.
Left / Right Arrow In horizontal menubar Moves focus to the previous or next top-level menu item, wrapping at the ends. If a menu is open, switches to the adjacent item's submenu.
Down / Up Arrow In horizontal menubar Opens the focused item's submenu and moves focus to its first item (Down) or last item (Up).
Down / Up Arrow Inside popup menu Moves focus to the next or previous item inside the open menu, wrapping at the top and bottom.
Right Arrow Inside popup menu Opens a nested submenu and focuses its first item. If the item has no submenu, moves to the next top-level menubar item and opens its submenu.
Left Arrow Inside popup menu Closes a nested submenu and returns focus to its parent item. From a first-level dropdown, moves to the previous top-level menubar item.
Enter / Space Menubar or popup menu Opens a submenu and focuses its first item, or activates the leaf item (updating checkbox/radio state) and closes the menu.
Escape Inside popup menu Closes the current menu and returns focus to its parent menu item.
Home / End Menubar or popup menu Moves focus to the first or last item in the current menubar or open menu.
Printable Characters Menubar or popup menu Moves focus to the next item in the current menu whose visible label starts with the typed character.

ARIA Roles & Attributes

Semantic ARIA roles and states expose the menu hierarchy, selection state, and grouping to assistive technologies:

ARIA Role / Attribute Target Element Description / Usage
role="menubar" Top-level list Identifies a persistent horizontal bar of top-level menu items.
role="menu" Popup / Submenu list Identifies a popup container offering a list of choices or nested submenus.
role="menuitem" Menu action / trigger Identifies an interactive action or submenu trigger inside a menubar or menu.
role="menuitemcheckbox" Toggleable option A menu item with an independent on/off state conveyed via aria-checked.
role="menuitemradio" Exclusive option A mutually exclusive menu item within a role="group", conveyed via aria-checked.
role="group" / role="separator" Option groups & dividers Groups related radio options with an accessible label and visually/semantically separates sections.
role="none" List item wrappers Removes implicit list item semantics from <li> wrappers so screen readers only count menu items.
aria-haspopup="true" Submenu triggers Indicates that activating the menu item opens a popup role="menu".
aria-expanded="true / false" Submenu triggers Communicates whether the associated popup menu is currently open or closed.
tabindex="0 / -1" Roving focus target Maintains a single tab stop on the active top-level menubar item while arrow keys move focus.
