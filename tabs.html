Accessible Tabs

A fully functional, keyboard-friendly tab interface featuring both automatic and manual activation variants, built with semantic HTML and ARIA standards.

Automatic Activation

Pressing Left/Right arrow keys will immediately change the active tab and display its content.

Sleek Glassmorphism

We combine deep background colors with semi-transparent, frosted-glass effects. The visual hierarchy is established through precise box shadows and solid borders that outline interactive elements.

Modern Typefaces

Our library relies heavily on modern sans-serif fonts such as Inter, ensuring maximum legibility across different devices and providing a clean, contemporary feel.

Delightful Feedback

Every interactive state (hover, focus, active) provides immediate visual feedback through micro-animations, reinforcing user actions without overwhelming the interface.

Manual Activation

Pressing Left/Right arrow keys will only move focus. Press Space or Enter to activate the tab.

Component Overview

Manual activation is recommended when tab panels contain content that takes a long time to load or when moving focus through the tabs without activating them is preferred.

Getting Started

Include the css/tabs.css and js/tabs.js files in your project. Structure your HTML using role="tablist", role="tab", and role="tabpanel".

Accessibility API

The component relies on setting data-activation="manual" on the tablist. All focus management and ARIA updates are handled automatically by the JavaScript module.

Accessibility Standards

Keyboard Navigation

The tabs component manages focus and arrow key navigation according to W3C WAI-ARIA guidelines:

Key Function
Tab When focus moves into the tab list, it places focus on the active tab element. Successive tabs move focus outside the tablist to the tab panel or next focusable element.
Left Arrow / Right Arrow Moves focus to the previous or next tab. If on the last tab, focus wraps to the first (and vice versa). In Automatic mode, this also activates the tab.
Up Arrow / Down Arrow Performs the same function as Left/Right arrows, but only active when the tablist uses aria-orientation="vertical".
Home / End Moves focus to the first or last tab element in the list, respectively.
Space / Enter Activates the currently focused tab if the component is set to Manual Activation mode.

ARIA Roles & Attributes

The markup uses semantic ARIA properties to communicate the relationships and state of the tabs to screen readers:

ARIA Role / Attribute Target Element Description / Usage
role="tablist" Container Identifies the element that serves as the container for the set of tabs.
role="tab" Tab Button Identifies the element as a tab that controls the visibility of an associated tab panel.
role="tabpanel" Content Box Identifies the element that contains the content associated with a specific tab.
aria-selected="true / false" Tab Button Indicates to assistive technologies whether the tab is currently active and its panel is displayed.
aria-controls="[ID]" Tab Button Points to the ID of the associated tab panel, establishing a relationship between the controller and the controlled element.
aria-labelledby="[ID]" Tab Panel Points to the ID of the associated tab button to provide an accessible name for the panel region.
