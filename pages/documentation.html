Documentation

Learn how to run the Accessible Components Library locally and add new accessible components to the unified application shell.

1. Getting the Code

You can clone this library directly from GitHub to your local machine. You will need Git installed.

git clone https://github.com/konainm/Accessible-Patterns.git
cd Accessible-Patterns

Alternatively, you can visit the GitHub Repository and download the project as a ZIP file.

2. Running Locally

Because the unified app shell fetches component templates dynamically, the project should be served over HTTP rather than opened directly via the file:// protocol.

Option A: Using npm (Recommended)

If you have Node.js installed, install dependencies and run the included start script:

npm install
npm start

Then open your browser and navigate to http://localhost:8080.

Option B: Using Python

If you have Python 3 installed, you can start a simple HTTP server from the project root:

python -m http.server 8080

Then open your browser and navigate to http://localhost:8080.

3. Unified App Shell Architecture

The site uses a single-entry app shell (index.html) for the shared header, navigation, global search, theme/viewport controls, and footer. Each component lives in its own focused files and is loaded on demand:

  • Template: Add a pure HTML fragment in components/<name>.html (no repeated header, footer, or boilerplate).
  • Styles & Script: Add css/<name>.css and js/<name>.js.
  • Registration: Register the component once in js/registry.js to automatically wire up routing, the homepage grid, footer links, and global search.

4. Usage Guidelines

When incorporating these patterns into your own projects, please remember:

  • Preserve ARIA attributes: Do not remove aria-* or role="*" attributes from the HTML structures. They are essential for screen readers.
  • Keyboard testing: Always test any modifications using only your keyboard (Tab, Shift+Tab, Arrows, Space, Enter, Escape).
  • Color Contrast: If you change the CSS variables (e.g., --bg-primary, --text-primary), verify that the contrast ratio remains at least 4.5:1 for normal text.
