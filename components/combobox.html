Accessibility Standards

Keyboard Navigation

The combobox component implements the W3C WAI-ARIA Authoring Practices Guide (APG) keyboard interaction model:

Key Function
Down Arrow Opens the listbox if closed. When open, moves visual focus (aria-activedescendant) to the next option, wrapping to the first option from the end.
Up Arrow Opens the listbox if closed. When open, moves visual focus to the previous option, wrapping to the last option from the start.
Alt + Down / Up Arrow Alt + Down opens the listbox without moving focus; Alt + Up closes the listbox.
Enter Selects the active option, updates the combobox value, and closes the listbox.
Escape Closes the listbox if open. In the editable combobox, pressing Escape when closed clears the input value.
Home / End In the select-only combobox, moves visual focus to the first or last option. In the editable combobox, moves the text cursor.
Printable Characters In the editable combobox, filters matching options and announces the count. In the select-only combobox, jumps to matching options via type-ahead.

ARIA Roles & Attributes

Semantic ARIA attributes maintain the relationship between the combobox, its popup listbox, and live announcements:

ARIA Role / Attribute Target Element Description / Usage
role="combobox" Input / Button Identifies the element as a combobox that controls a popup listbox.
aria-expanded="true / false" Combobox Indicates whether the associated listbox popup is currently displayed.
aria-controls="[ID]" Combobox References the ID of the popup role="listbox" element.
aria-autocomplete="list" Editable Input Informs assistive technologies that typing filters a list of suggested options.
aria-activedescendant="[ID]" Combobox Tracks the currently highlighted option while keeping DOM focus on the combobox.
role="listbox" / role="option" Popup & Items Defines the popup list container and its selectable options with aria-selected.
aria-live="polite" Status Region Announces filtered result counts and newly selected values to screen readers.
