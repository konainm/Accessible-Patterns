Tooltip

Fully accessible tooltips and non-modal popover dialogs built with WAI-ARIA standards.

Standard Tooltips (Hover / Focus)

Purely informational tooltips that appear on hover or keyboard focus. They do not receive focus themselves and can be dismissed with the Escape key.

Tooltip Dialogs / Toggletips (Click)

Rich tooltips treated as non-modal dialogs. Triggered by click, allowing users to move focus inside them if necessary. Dismissed by clicking outside or pressing Escape.

Toggletip

A toggletip is a UI component used to display supplemental information. Unlike a standard tooltip, it is toggled by click and can contain richer formatting.

Accessibility Standards

Keyboard Navigation

The tooltip and toggletip components follow specific W3C WAI-ARIA keyboard interaction patterns:

Key Context Action
Tab When focus is outside Moves focus to the tooltip trigger. Standard tooltips will display automatically on focus.
Enter / Space When focus is on Toggletip Trigger Toggles the visibility of the interactive toggletip dialog.
Escape When tooltip/toggletip is open Closes the open tooltip or toggletip and ensures focus is on the triggering element.
Tab / Shift + Tab When focus is inside Toggletip Moves focus through the interactive elements inside the dialog, following standard tab order.

ARIA Roles & Attributes

The markup uses semantic ARIA properties to communicate the state and purpose of the tooltip to screen readers:

ARIA Role / Attribute Target Element Purpose
role="tooltip" Tooltip Container Identifies the element as a standard tooltip. Applied to hover/focus tooltips.
aria-describedby="[ID]" Trigger Element Points to the ID of the standard tooltip, reading its content when the trigger is focused.
role="dialog" Toggletip Container Identifies rich tooltips as non-modal dialogs, allowing users to interact with contents.
aria-expanded="true/false" Toggletip Trigger Communicates the open/closed state of a rich tooltip dialog to screen readers.
